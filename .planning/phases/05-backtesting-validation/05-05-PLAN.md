Design notes:
1. These are integration-level tests but still use mocked DB — they test the ORCHESTRATION LOGIC of WalkForwardOptimizer.run() without requiring a live PostgreSQL instance or real strategy execution.
2. The "full run activates params" test patches _fetch_all_candles to return synthetic candles that satisfy the minimum count guard, then patches _activate_best_params with AsyncMock to capture calls, and lets _evaluate_all_combos run against the synthetic candles. This tests that the orchestration pathway from "sufficient data → evaluate → activate" works end-to-end.
3. Use unittest.mock.patch and AsyncMock (from unittest.mock) for all DB-touching methods.

Key implementation details:

For the synthetic candle dataset, generate candles using the make_candles() pattern from tests/test_strategies/conftest.py. The counts must satisfy MIN_CANDLES_FOR_OPTIMIZER:
- D1: 300 candles (above 257 minimum)
- H4: 1600 candles (above 1542 minimum)
- H1: 6500 candles (above 6171 minimum)
- M15: 25000 candles (above 24685 minimum)

Creating 25000+ candles inline would be slow. Instead, for the full-run test, either:
a. Patch _check_sufficient_data to return True directly, AND patch _fetch_all_candles to return small but valid candle sets, AND patch _evaluate_all_combos to return a pre-built "passing" result dict (bypassing real LHS/backtest). This tests the orchestration logic without running the computationally heavy parts.
b. Only the data-guard and WFE-gate tests use real logic; the full activation test patches the heavy parts.

Recommended approach (a) for the integration test:
```python
@pytest.mark.asyncio
async def test_optimizer_full_run_activates_params():
    """End-to-end: sufficient data + passing combo → _activate_best_params called."""
    from datetime import datetime, timezone, timedelta
    from src.backtesting.walk_forward import WalkForwardWindow
    from src.backtesting.optimizer import WalkForwardOptimizer
    from unittest.mock import patch, AsyncMock

    fake_window = WalkForwardWindow(
        window_num=3,
        train_start=datetime(2024, 1, 1, tzinfo=timezone.utc),
        train_end=datetime(2024, 7, 1, tzinfo=timezone.utc),
        oos_start=datetime(2024, 7, 1, tzinfo=timezone.utc),
        oos_end=datetime(2024, 9, 1, tzinfo=timezone.utc),
    )
    passing_result = {
        "combo": {"param_a": 0.5, "param_b": 0.7, "param_c": 2.0},
        "best_wfe": 0.65,
        "is_score": 1.8,
        "oos_score": 1.17,
        "oos_pf_per_window": [1.3, 1.1, 1.2],
        "trade_count": 42,
        "win_rate": 0.55,
        "max_dd": 150.0,
        "latest_window": fake_window,
        "all_oos_pnl": [10.0, -5.0, 15.0, -3.0, 8.0] * 8,  # 40 trades, profitable
    }

    optimizer = WalkForwardOptimizer()

    # Patch: sufficient data (skip real fetch), evaluate returns passing result, activate is captured
    with patch.object(optimizer, "_fetch_all_candles", new=AsyncMock(return_value={
        "D1": [object()] * 300, "H4": [object()] * 1600,
        "H1": [object()] * 6500, "M15": [object()] * 25000,
    })), patch.object(optimizer, "_evaluate_all_combos", new=AsyncMock(return_value=passing_result)), \
         patch.object(optimizer, "_activate_best_params", new=AsyncMock()) as mock_activate:
        await optimizer.run()

    assert mock_activate.call_count == 4  # called once per strategy (all pass)
```
