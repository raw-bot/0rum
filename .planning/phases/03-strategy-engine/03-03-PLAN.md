**PARAM_RANGES** (exactly 3 optimizable parameters per STRAT-05 and CLAUDE.md §9.4):
```python
PARAM_RANGES = {
    "squeeze_lookback": (12.0, 30.0),  # Minimum H4 consolidation candles to qualify as range
    "volume_mult":      (1.2, 2.5),    # Volume threshold at breakout (× SMA20 volume)
    "sl_atr_mult":      (0.5, 1.5),    # SL as distance into range mid-point (×ATR14)
}
```

**Detection logic (per CLAUDE.md §9.4 steps 1-6):**
1. Compute ATR(14) on H4 candles.
2. Identify range: take the last `int(params["squeeze_lookback"])` H4 candles. Compute range_high = max(c.high for c in window), range_low = min(c.low for c in window), range_width = range_high - range_low. Check if range_width < 1.5 × ATR14(H4). If not, return [].
3. Breakout check on H1 candles: look at the most recent H1 candle. Check:
   - BUY: `h1_candle.close > range_high` (closes above range)
   - SELL: `h1_candle.close < range_low` (closes below range)
   If no breakout, check 2nd most recent H1 candle as well (fresh breakout only — last 2 candles).
4. Volume confirmation: `h1_breakout_candle.volume > volume_mult × SMA20_volume(H1)`. SMA20 computed over last 20 H1 candles before the breakout candle. If volume condition fails, return [].
5. Entry: Per CLAUDE.md §9.4 — "on retest of the broken level (if in the next 4 H1 candles), else at the breakout close". For initial implementation, use breakout close as entry (retest tracking is stateful and belongs to Phase 4 pipeline).
6. SL: mid-range adjusted by sl_atr_mult: `sl = (range_high + range_low) / 2 ± sl_atr_mult × ATR14(H4)`. For BUY: `sl = range_mid - sl_atr_mult × ATR14`. For SELL: `sl = range_mid + sl_atr_mult × ATR14`.
7. TP1: `entry + range_width` (BUY) or `entry - range_width` (SELL). TP = 1× range width per CLAUDE.md §9.4 (FIXED, not optimized).
8. TP2: None (Breakout Expansion has no TP2 defined in spec).

**Confidence scoring (D-01: linear weighted sum, no sigmoid, no exp):**
```python
# Confidence weights for BreakoutExpansion:
# w_squeeze_duration = 0.35 — longer squeeze = more compressed energy = higher quality breakout
#   (actual lookback count / max_lookback, normalized 0-1. squeeze_lookback=30 → 1.0)
# w_volume_ratio = 0.45 — volume confirmation is the strongest signal for breakout quality
#   (volume at breakout / SMA20_volume, normalized: (ratio - 1.0) / (volume_mult_max - 1.0), capped at 1.0)
#   Note: volume_mult_max = 2.5 (PARAM_RANGES max). This normalizes relative to the max expected multiplier.
# w_range_clarity = 0.20 — tight range with well-defined boundaries is more reliable
#   (1.0 - range_width / (1.5 × ATR14), capped at [0,1]. Tighter range → higher clarity)
# Weights sum = 0.35 + 0.45 + 0.20 = 1.00

W_SQUEEZE_DURATION = 0.35
W_VOLUME_RATIO = 0.45
W_RANGE_CLARITY = 0.20

squeeze_duration_norm = min(actual_lookback_count / 30.0, 1.0)

vol_ratio = float(breakout_candle.volume) / max(sma20_volume, 1)
volume_ratio_norm = max(0.0, min((vol_ratio - 1.0) / (2.5 - 1.0), 1.0))

range_clarity_norm = max(0.0, 1.0 - float(range_width) / max(1.5 * atr_h4, 1e-9))

confidence = W_SQUEEZE_DURATION * squeeze_duration_norm + W_VOLUME_RATIO * volume_ratio_norm + W_RANGE_CLARITY * range_clarity_norm
confidence = max(0.0, min(confidence, 1.0))  # D-03: clamp
```

# w_crossover_angle = 0.40 — angle of crossover indicates momentum strength
#   (diff between fast and slow EMA at crossover point, normalized by ATR14: |ema_fast-ema_slow| / atr, capped at 1.0)

#   (|ema_fast - ema50| / atr, capped at 1.0. Larger distance from EMA50 = stronger trend)
# w_trend_alignment = 0.25 — categorical: fast EMA and price are aligned with longer trend
#   (1.0 if close > ema50 for BUY and close < ema50 for SELL, else 0.5)
# Weights sum = 0.40 + 0.35 + 0.25 = 1.00

W_CROSSOVER_ANGLE = 0.40
W_EMA50_DISTANCE = 0.35
W_TREND_ALIGNMENT = 0.25

atr_h1 = self.calculate_atr(h1_candles, period=14)

# Crossover angle: separation between EMAs normalized by ATR
ema_separation = abs(float(ema_fast[-1]) - float(ema_slow[-1]))
crossover_angle_norm = min(ema_separation / max(atr_h1, 1e-9), 1.0)
