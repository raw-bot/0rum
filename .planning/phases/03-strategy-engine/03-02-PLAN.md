```python
PARAM_RANGES = {
    "sweep_atr_mult": (0.2, 0.8),   # Minimum sweep depth filter (×ATR14)
    "sl_atr_mult":    (0.3, 1.0),   # SL distance beyond sweep wick (×ATR14)
    "tp_risk_mult":   (1.2, 3.0),   # TP1 as multiple of entry→SL risk
}
```

**Detection logic (per CLAUDE.md §9.2 steps 1-7):**
1. Detect swing highs/lows on H4 candles via `self.detect_swing_levels(h4_candles, order=10)` — these are S/R levels
2. Also check D1 candles for major levels if D1 candles available
3. For each M15 candle (most recent 50 candles to limit computation): check if any candle's wick pierces a swing level by > `sweep_atr_mult × ATR14(M15)` but the close returns to the other side
   - Sweep of support (BUY signal): `candle.low < level - sweep_atr_mult*atr` AND `candle.close > level`
   - Sweep of resistance (SELL signal): `candle.high > level + sweep_atr_mult*atr` AND `candle.close < level`
4. Take the most recent qualifying sweep candle (newest first, break after first found)
5. Entry: close of the sweep candle
6. SL (BUY): `min(candle.low, level) - sl_atr_mult × ATR14(M15)`. SL (SELL): `max(candle.high, level) + sl_atr_mult × ATR14(M15)`
7. TP1: `entry + tp_risk_mult × |entry - sl|` for BUY, `entry - tp_risk_mult × |sl - entry|` for SELL
8. TP2: distance from entry to TP1 doubled and added to TP1 (i.e. TP2 = entry + 2 × (TP1 - entry) for BUY)

**Confidence scoring (D-01: linear weighted sum, no sigmoid, no exp):**
```python
# Confidence weights for LiquiditySweep:
# w_sweep_depth = 0.40 — sweep depth quality is the primary signal driver
#   (how far below/above the level price swept, normalized by ATR)
# w_volume_spike = 0.35 — volume expansion confirms institutional activity
#   (volume at sweep candle vs 20-period SMA volume, normalized 0-1, capped at 1.0)
# w_proximity = 0.25 — proximity to a major level increases signal reliability
#   (how many swing levels within 1.0×ATR of the swept level, normalized 0-1)
# Weights sum = 0.40 + 0.35 + 0.25 = 1.00

W_SWEEP_DEPTH = 0.40
W_VOLUME_SPIKE = 0.35
W_PROXIMITY = 0.25

# Normalize sweep depth: depth / (2.0 * atr), capped at 1.0
sweep_depth_norm = min(sweep_depth / (2.0 * atr), 1.0)

# Normalize volume: (candle_volume - sma_volume) / sma_volume, capped at [0, 1]
# If no volume data, use 0.5 as neutral fallback
vol_ratio = (float(sweep_candle.volume) / max(sma_vol, 1)) - 1.0
volume_spike_norm = max(0.0, min(vol_ratio, 1.0))

# Normalize proximity: count of swing levels within 1.0×ATR, normalized by 3 (max expected)
proximity_count = sum(1 for lvl in all_swing_levels if abs(lvl - level) < atr)
proximity_norm = min(proximity_count / 3.0, 1.0)

confidence = W_SWEEP_DEPTH * sweep_depth_norm + W_VOLUME_SPIKE * volume_spike_norm + W_PROXIMITY * proximity_norm
confidence = max(0.0, min(confidence, 1.0))  # D-03: clamp as safety guard
```

4. Entry trigger on M15 (most recent 4 candles): detect price action confirmation:

   - Pin bar: wick > 2× body (check abs(high-low) > 2*abs(close-open) with close near top/bottom)
   - Inside bar breakout: current_high > prev_high (BUY) or current_low < prev_low (SELL) after a narrow range candle

5. Entry: close of the M15 confirmation candle
6. SL (BUY): pullback low − `sl_atr_mult × ATR14(H1)`. SL (SELL): pullback high + `sl_atr_mult × ATR14(H1)`

```python
# Confidence weights for TrendContinuation:
# w_trend_strength = 0.45 — trend quality is the dominant factor for this strategy
#   (ADX(14) on H1 normalized: adx/50.0 capped at 1.0. ADX > 25 = strong trend)
#   ADX computed from H1 candles using directional movement index formula.
# w_pullback_quality = 0.35 — clean pullback to EMA zone without overextension
#   (distance of touch from EMA normalized: 1.0 - min(gap/atr, 1.0), i.e. closer = better)
# w_pa_pattern = 0.20 — price action confirmation pattern quality
#   (1.0 for engulfing, 0.7 for pin bar, 0.5 for inside bar breakout)
# Weights sum = 0.45 + 0.35 + 0.20 = 1.00

W_TREND_STRENGTH = 0.45
W_PULLBACK_QUALITY = 0.35
W_PA_PATTERN = 0.20

# Compute ADX(14) from H1 candles or fall back to 0.5 if insufficient data
adx_value = self._compute_adx(h1_candles, period=14)
trend_strength_norm = min(adx_value / 50.0, 1.0)

# Pullback quality: how close price came to the EMA (closer = cleaner pullback)
gap = abs(float(pullback_candle.low if trend == BUY else pullback_candle.high) - ema_pb_value)
pullback_quality_norm = max(0.0, 1.0 - min(gap / max(atr_h1, 1e-9), 1.0))

# PA pattern score
pa_score = {"engulfing": 1.0, "pin_bar": 0.7, "inside_bar": 0.5}.get(pattern_type, 0.5)

confidence = W_TREND_STRENGTH * trend_strength_norm + W_PULLBACK_QUALITY * pullback_quality_norm + W_PA_PATTERN * pa_score
confidence = max(0.0, min(confidence, 1.0))  # D-03: clamp
```

**ADX helper:** Implement `_compute_adx(candles: list, period: int = 14) -> float`. Simplified ADX:
- +DM = max(high - prev_high, 0) when > abs(low - prev_low)
- -DM = max(prev_low - low, 0) when > abs(high - prev_high)
- TR as in calculate_atr
- Wilder smooth DM+ and DM-: same alpha=1/period as ATR
- DI+ = 100 × DM+smooth / ATRsmooth, DI- = 100 × DM-smooth / ATRsmooth
- DX = 100 × |DI+ - DI-| / (DI+ + DI-), ADX = Wilder smooth of DX
- Return 0.0 if < 28 candles (2×period)
