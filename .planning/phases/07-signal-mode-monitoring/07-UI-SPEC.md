# Phase 7 — UI Design Contract

> Visual and interaction contract for the `/dashboard` operator page.
> Generated by gsd-ui-researcher. Consumed by gsd-planner, gsd-executor, gsd-ui-auditor.

---

## Design System

| Property | Value | Source |
|----------|-------|--------|
| Tool | none | D-26: no external CDN, no build step |
| Preset | not applicable | — |
| Component library | none — plain HTML + CSS | D-21 |
| Icon library | Unicode characters / inline SVG only | D-26 (no CDN) |
| Font | `system-ui, -apple-system, "Segoe UI", Roboto, monospace` (system stack) | D-26 (no Google Fonts) |

**Stack constraints (locked by D-21, D-26):**
- Delivery: single `.html` file — Jinja2 template (`templates/dashboard.html`) served by FastAPI
- Styling: `<style>` block embedded in the HTML file — no external `.css` file, no CDN
- JS: vanilla `fetch` + `setInterval` — no Alpine.js, no CDN dependency
- No React, no bundler, no build step

## Spacing Scale

Declared values (must be multiples of 4). Dense trading-terminal aesthetic — tighter than consumer defaults.

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Label-to-value gaps, badge padding |
| sm | 8px | Cell padding, icon-to-text gap |
| md | 16px | Card internal padding, row gaps in tables |
| lg | 24px | Section padding (between dashboard sections) |
| xl | 32px | Page-level horizontal padding |
| 2xl | 48px | Vertical gap between major sections |
| 3xl | 64px | Not used — dashboard is dense, not spacious |

Exceptions:
- Status indicator dots: 8×8px (not on scale, necessary for inline status badges)
- Table row height: 28px (tight data rows, intentional density — Bloomberg terminal reference)
- Section header height: 32px

## Typography

Trading terminal aesthetic: monospace for data values, sans-serif for labels. System fonts only — no CDN.

| Role | Size | Weight | Line Height | Font family | Usage |
|------|------|--------|-------------|-------------|-------|
| Body / Label | 13px | 400 | 1.4 | `system-ui, -apple-system, "Segoe UI", Roboto, sans-serif` | Section headers, table column headers, status labels |
| Data Value | 13px | 600 | 1.4 | `"SF Mono", "Fira Code", "Courier New", monospace` | Prices, P&L numbers, percentages, signal levels |
| Section Heading | 11px | 600 | 1.2 | `system-ui, -apple-system, sans-serif` | Section titles (uppercase, letter-spacing: 0.08em) |
| Display / Alert | 20px | 600 | 1.2 | `system-ui, -apple-system, sans-serif` | Circuit breaker state, execution mode badge |

**Typography rules:**
- Section headings: ALL CAPS, letter-spacing 0.08em, color `var(--color-muted)`
- Data values (prices, P&L): always monospace to prevent layout shift during polling updates
- No more than 4 font sizes in the page — 11px / 13px / 13px mono / 20px
- Font weights: 400 (regular) and 600 (semibold) only

## Color

Dark theme. High contrast. Functional signal colors only — no decorative color.

| Role | Value | Usage | Source |
|------|-------|-------|--------|
| Dominant (60%) | `#0d0f11` | Page background, table row background | D-26 dark theme; default |
| Secondary (30%) | `#161a1e` | Card/section backgrounds, table header rows, status bar | default — one step lighter than dominant |
| Accent (10%) | `#00c896` | Reserved for: positive P&L values, "LIVE" / "SENT" execution status badges, BUY direction indicator dots | default — terminal green, Bloomberg-like |
| Destructive | `#e05252` | SL close reason, negative P&L values, circuit breaker TRIPPED state, SELL direction indicator dots | default — muted red, not harsh |
| Warning | `#d4a017` | TP1_HIT state badge, TRAIL close reason, HIGH_VOL regime badge | default — amber, distinct from green/red |
| Muted | `#5a6272` | Section headings, table column headers, helper text, secondary labels | default |
| Border | `#252a31` | Card borders, table dividers, section separators | default — barely visible on dark bg |
| Text Primary | `#d8dce3` | All primary text — labels, table cell text | default — off-white, not pure white |
| Text Secondary | `#8a939f` | Secondary data, timestamps, strategy names in sub-rows | default |

**Color rules:**
- Accent (`#00c896`) is reserved exclusively for: positive P&L, BUY direction, SENT status. Never used decoratively.
- Destructive (`#e05252`) is reserved exclusively for: negative P&L, SELL direction, SL close reason, CB TRIPPED.
- Warning (`#d4a017`) is reserved exclusively for: TP1_HIT, TRAIL, HIGH_VOL. Never used for non-state elements.
- Background never uses pure black (`#000000`) — `#0d0f11` only.
- No gradients. Flat colors only — trading terminal aesthetic, not SaaS landing page.
- No box shadows for decoration. Only a `1px solid var(--border)` border on cards.

**CSS custom properties (executor must declare these on `:root`):**
```css
:root {
  --bg:          #0d0f11;
  --surface:     #161a1e;
  --accent:      #00c896;
  --destructive: #e05252;
  --warning:     #d4a017;
  --muted:       #5a6272;
  --border:      #252a31;
  --text:        #d8dce3;
  --text-2:      #8a939f;
}
```

## Layout

Single-page, vertical-scroll layout. No sidebar. Full-width sections.

```
┌─────────────────────────────────────────────────────┐
│  HEADER BAR — bot name, execution mode, CB state,   │
│  last updated timestamp, [Refresh] button            │
├─────────────────────────────────────────────────────┤
│  STATUS ROW — DB health, Redis health, active        │
│  strategies count, daily P&L                         │
├──────────────────┬──────────────────────────────────┤
│  OPEN TRADES     │  PER-STRATEGY STATS               │
│  (left, 50%)     │  (right, 50%)                     │
├──────────────────┴──────────────────────────────────┤
│  LATEST SIGNALS — table, last 20 approved signals    │
└─────────────────────────────────────────────────────┘
```

- Page max-width: none — full viewport width
- Page padding: `xl` (32px) horizontal, `lg` (24px) top
- Grid: CSS Grid `grid-template-columns: 1fr 1fr` for the two-column section
- Sections below 768px viewport width: stack to single column
- No sticky header (operator tool, not a long-scroll consumer page)
- Table rows: zebra striping using `--surface` / `--bg` alternation

## Sections and Component Inventory

### 1. Header Bar

**Elements:**
- Left: bot name "0rum" in Display size (20px, weight 600, `--text`)
- Center: execution mode badge — `SIGNAL` or `AUTO` — pill shape, 8px vertical padding, 12px horizontal, font 11px uppercase
  - SIGNAL mode: background `#1a2d26`, text `--accent`, border `--accent` at 40% opacity
  - AUTO mode: background `#2d1a1a`, text `--destructive`, border `--destructive` at 40% opacity
- Right: last updated timestamp (`--text-2`, 13px), then [Refresh] button

**Refresh button:**
- Label: "Refresh" (no icon) — see Copywriting section
- Style: `border: 1px solid var(--border)`, background `--surface`, text `--text`, padding 6px 16px, font-size 13px
- Hover state: background `#1e2329` (one step lighter than surface)
- No rounded corners beyond 4px — sharp, functional look
- Keyboard: focusable, `Enter` triggers refresh

**Auto-refresh:** `setInterval` every 30 seconds calling `fetchDashboard()`. No visible ticker. The timestamp updates to show staleness.

### 2. Status Row

Four status cells in a horizontal flex row, separated by `--border` dividers.

| Cell | Content |
|------|---------|
| DB | Label "DATABASE" + dot indicator (8×8px circle) — green (`--accent`) if healthy, red (`--destructive`) if unreachable |
| Redis | Label "REDIS" + dot indicator — same pattern |
| Active Strategies | Label "STRATEGIES" + numeric value (monospace, 13px) from `strategies_active` |
| Daily P&L | Label "DAILY P&L" + value in percent with sign (monospace, 13px, color `--accent` if ≥ 0, `--destructive` if < 0) |

### 3. Open Trades Panel

Section heading: "OPEN TRADES" (11px, uppercase, `--muted`)

Table columns: Direction | Strategy | Entry | Current SL | TP1 | Size | Status | Age

- Direction: colored dot + text ("BUY" green, "SELL" red)
- Status badge: "OPEN" (neutral `--text-2`) or "TP1 HIT" (warning `--warning` background pill)
- Age: human-readable elapsed time e.g. "2h 14m" (`--text-2`)
- All price values: monospace font
- Empty state: single row with centered text "No open theoretical trades" (`--muted`, 13px)

### 4. Per-Strategy Stats Panel

Section heading: "STRATEGY PERFORMANCE" (11px, uppercase, `--muted`)

Table columns: Strategy | Trades | Win Rate | Profit Factor | Total P&L

- Win rate: percentage, monospace
- Profit factor: decimal to 2 places, monospace; green if ≥ 1.0, red if < 1.0
- Total P&L: signed percent, monospace; green/red colored by sign
- Empty state: "No strategy stats yet" (`--muted`, 13px)

### 5. Latest Signals Table

Section heading: "LATEST SIGNALS — LAST 20" (11px, uppercase, `--muted`)

Table columns: Time | Strategy | Direction | Entry | SL | TP1 | TP2 | Confidence | Size | Status

- Time: UTC timestamp, `--text-2`
- Direction: colored dot + "BUY" / "SELL"
- Confidence: percentage (monospace)
- Status badge: "SENT" (accent), "PENDING" (muted), "FAILED" (destructive)
- All price values: monospace
- Empty state: "No signals in the database yet" (`--muted`, 13px)

### 6. Circuit Breaker State

Displayed inline in the Header Bar (between mode badge and timestamp) when `cb_tripped = true`:

- Pill badge: background `#2d1a1a`, text `--destructive`, border `--destructive` at 40% opacity
- Label: "CIRCUIT BREAKER TRIPPED"
- When not tripped: hidden (no empty space)

## Data Source Contract

Dashboard fetches `/api/dashboard` on page load and every 30 seconds.

Expected JSON shape (executor must match exactly):
```json
{
  "health": {
    "db": true,
    "redis": true,
    "strategies_active": 1
  },
  "execution_mode": "signal",
  "circuit_breaker": {
    "tripped": false,
    "consecutive_stops": 2
  },
  "daily_pnl_pct": 0.012,
  "open_trades": [...],
  "latest_signals": [...],
  "strategy_stats": [...]
}
```

Fetch error handling: if `/api/dashboard` returns non-200 or throws, display an error banner below the header bar (see Copywriting — Error State).

## Interaction Contract

| Interaction | Behavior | Implementation |
|-------------|----------|----------------|
| Page load | Fetch `/api/dashboard`, render data | `fetch('/api/dashboard')` in `DOMContentLoaded` |
| Auto-refresh | Re-fetch every 30 seconds, update all data in place | `setInterval(fetchDashboard, 30000)` |
| Manual refresh | Re-fetch immediately on button click, update timestamp | `button.addEventListener('click', fetchDashboard)` |
| Refresh in flight | Button disabled during fetch, label "Refreshing..." | `button.disabled = true` during fetch |
| API error | Show error banner, keep stale data visible | Do not clear panels on error — show last known state |
| Timestamp update | After each successful fetch, update "Last updated HH:MM:SS UTC" | Format with `toISOString()` trimmed to seconds |

**No other interactions.** No sorting, no filtering, no expanding rows, no modals. Read-only display only (D-22).

## Accessibility

Minimum operator-tool baseline:
- All status colors also communicate state via text (dot + label, not dot alone) — colorblind safe
- Table `<th>` elements with `scope="col"` for all column headers
- `<button>` for the Refresh button (not `<div onclick>`)
- Page `lang="en"` on `<html>`
- No animation — no transitions, no CSS keyframes (operator viewing during live trading, no distraction)
