<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| HTTP client → /health | The health endpoint is read-only; it does not accept user input. No untrusted data enters the risk module calls. |
| /health → Redis (BreakerManager) | BreakerManager reads from Redis; circuit_breaker state is operator-internal. |
| /health → PostgreSQL (gates) | get_open_positions / get_daily_pnl_pct execute parameterized SELECT queries on TradeORM. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-06-09-01 | DoS | BreakerManager() creates a new Redis connection on every /health call | mitigate | BreakerManager is instantiated inside a try/except; if connection creation is slow (Redis unreachable), the try/except degradation path activates within the FastAPI request timeout. Mitigation: if health.py already holds a Redis client, pass it to BreakerManager(redis=...) to reuse the connection. Executor must check this when reading health.py. |
| T-06-09-02 | Availability | Risk module exception propagates as HTTP 500 | mitigate | The try/except block in Task 1 catches all Exception subclasses and degrades to placeholder values, ensuring /health always returns 200. Test 3 verifies this invariant. |
| T-06-09-03 | Information Disclosure | daily_pnl_pct in /health response leaks operator's P&L to any caller | accept | /health is an operator-only endpoint (no auth required by design in v1 — CLAUDE.md confirms no auth module exists yet). The v1 trust model accepts this. Auth is a Phase 7+ concern. |
| T-06-09-04 | Tampering | SQL injection via get_open_positions / get_daily_pnl_pct | mitigate | Both helpers use SQLAlchemy parameterized queries (no user-controlled input). Inherited from Plan 05's T-06-05-01 mitigation. No new surface introduced here. |

ASVS L1: no new auth/session/crypto surface. The /health endpoint is observability-only. Risk value reads are parameterized; degradation path is tested.
</threat_model>
