Evaluate flow (06-RESEARCH §5 — implement verbatim with structlog at each rejection):

1. `await self.breaker.reset_if_expired()` (idempotent; clears state if cooldown elapsed).
2. `if await self.breaker.is_tripped():` → log `risk.gate.rejected` with gate="circuit_breaker", reason="circuit_breaker_active"; return `RiskDecision(passed=False, reason="circuit_breaker_active")`. **NONE of the gates or sizer run** (D-12).
3. Gate 1: `passed, daily_pnl = await evaluate_daily_loss(session, self.settings.daily_loss_limit)`. If not passed → log + return `RiskDecision(passed=False, reason="daily_loss_limit")`. **DO NOT call breaker.record_stop** (D-15).
4. Gate 2: `passed, open_count = await evaluate_max_positions(session, self.settings.max_positions)`. If not passed → log + return `RiskDecision(passed=False, reason="max_positions")`.
5. Gate 3 (count only): `same_dir_count = await count_same_direction_open(session, candidate.direction.value)`. NEVER blocks (D-04).
6. Sizer: `sizing = calculate_position_size(equity=settings.theoretical_equity_usd, ...)`. Log `risk.sizing.calculated` with the breakdown.
7. Return `RiskDecision(passed=True, reason=None, sizing=sizing, concentration_reduced=sizing.concentration_reduced)`.

- `risk.gate.rejected` — emitted on every gate failure with `gate=`, `reason=`, `strategy=`, `direction=`, `entry_price=`, `signal_ref=id(candidate)`.
- `risk.sizing.calculated` — emitted after sizer with `strategy`, `direction`, `risk_pct`, `size_lots`, `vol_factor`, `concentration_reduced`.
