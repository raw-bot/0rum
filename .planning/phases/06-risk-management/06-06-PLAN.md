Class signature (D-11):
```python
class BreakerManager:
    def __init__(self, redis: aioredis.Redis | None = None):
        settings = get_settings()
        self._redis = redis or aioredis.from_url(settings.redis_url, decode_responses=True)
        self._stops_threshold = settings.circuit_breaker_stops          # default 8
        self._cooldown_seconds = settings.circuit_breaker_cooldown_hours * 3600  # default 86400

    async def is_tripped(self) -> bool: ...
    async def reset_if_expired(self) -> bool: ...
    async def record_stop(self, trade_id: UUID | None, strategy: str) -> CircuitBreakerAlert | None: ...
    async def record_win(self) -> None: ...
```

State transitions (06-RESEARCH Code Examples §breaker — implement verbatim):

`is_tripped`:
- Read CB_COOLDOWN_UNTIL. If None → False. Otherwise parse ISO-8601 and return `parsed > datetime.now(timezone.utc)`.

`reset_if_expired`:
- Read CB_COOLDOWN_UNTIL. If None → False. If parsed <= now → DELETE CB_TRIPPED_AT and CB_COOLDOWN_UNTIL, SET CB_COUNTER to 0, log `risk.circuit_breaker.reset` reason="cooldown_expired", return True. Else → False.

`record_stop`:
- new_count = await self._redis.incr(CB_COUNTER)
- if new_count >= self._stops_threshold:
    - tripped_at = datetime.now(timezone.utc); cooldown_until = tripped_at + timedelta(seconds=self._cooldown_seconds)
    - SET CB_TRIPPED_AT to tripped_at.isoformat()
    - SET CB_COOLDOWN_UNTIL to cooldown_until.isoformat() with `ex=self._cooldown_seconds`
    - Build CircuitBreakerAlert(tripped_at=..., consecutive_stops=new_count, cooldown_until=..., last_stop_strategy=strategy, last_stop_trade_id=trade_id)
    - log.warning("risk.circuit_breaker.tripped", consecutive_stops=new_count, cooldown_until=cooldown_until.isoformat())
    - return alert
- else: return None

`record_win`:
- SET CB_COUNTER to 0 (Redis stores as "0" with decode_responses=True)
- log.info("risk.circuit_breaker.counter_reset", reason="winning_trade")

Constructor (`__init__`):

```python
def __init__(self, redis: aioredis.Redis | None = None):
    """Constructor-injected Redis client. Default: aioredis.from_url(settings.redis_url, decode_responses=True).

    Note: decode_responses=True is REQUIRED — the breaker reads ISO-8601 strings.
    Without it, Redis returns bytes and datetime.fromisoformat raises TypeError.
    health.py uses ping() only and does not require decode_responses.
    """
    settings = get_settings()
    self._redis = redis or aioredis.from_url(settings.redis_url, decode_responses=True)
    self._stops_threshold = settings.circuit_breaker_stops
    self._cooldown_seconds = settings.circuit_breaker_cooldown_hours * 3600
```

Method `async def is_tripped(self) -> bool`:
```python
cooldown = await self._redis.get(CB_COOLDOWN_UNTIL)
if cooldown is None:
    return False
return datetime.fromisoformat(cooldown) > datetime.now(timezone.utc)
```

Method `async def reset_if_expired(self) -> bool`:
```python
"""Idempotent: returns False (no-op) when cooldown is absent or still in the future."""
cooldown = await self._redis.get(CB_COOLDOWN_UNTIL)
if cooldown is None:
    return False
if datetime.fromisoformat(cooldown) <= datetime.now(timezone.utc):
    await self._redis.delete(CB_TRIPPED_AT, CB_COOLDOWN_UNTIL)
    await self._redis.set(CB_COUNTER, 0)
    log.info("risk.circuit_breaker.reset", reason="cooldown_expired")
    return True
return False
```

Method `async def record_stop(self, trade_id: Optional[UUID], strategy: str) -> Optional[CircuitBreakerAlert]`:
```python
"""Increment consecutive-stop counter; trip and emit Alert if threshold reached.

Atomic INCR; cooldown_until written with redis TTL so the keys self-expire.
Returns the Alert ONLY on the trip; subsequent stops while tripped continue
to INCR but return None (the breaker is already tripped — Plan 07's runner
short-circuits new candidates anyway).
"""
new_count = await self._redis.incr(CB_COUNTER)
if new_count >= self._stops_threshold:
    tripped_at = datetime.now(timezone.utc)
    cooldown_until = tripped_at + timedelta(seconds=self._cooldown_seconds)
    await self._redis.set(CB_TRIPPED_AT, tripped_at.isoformat())
    await self._redis.set(
        CB_COOLDOWN_UNTIL,
        cooldown_until.isoformat(),
        ex=self._cooldown_seconds,
    )
    alert = CircuitBreakerAlert(
        tripped_at=tripped_at,
        consecutive_stops=new_count,
        cooldown_until=cooldown_until,
        last_stop_strategy=strategy,
        last_stop_trade_id=trade_id,
    )
    log.warning(
        "risk.circuit_breaker.tripped",
        consecutive_stops=new_count,
        cooldown_until=cooldown_until.isoformat(),
    )
    return alert
return None
```

Method `async def record_win(self) -> None`:
```python
await self._redis.set(CB_COUNTER, 0)
log.info("risk.circuit_breaker.counter_reset", reason="winning_trade")
```

Critical:
- The constants CB_COUNTER / CB_TRIPPED_AT / CB_COOLDOWN_UNTIL are MODULE-LEVEL, not class attributes — tests import them by name (06-RESEARCH §7).
- `decode_responses=True` MUST be on the constructor's default Redis URL — without it, `datetime.fromisoformat(cooldown)` fails on `bytes` input.

If a 9th, 10th… stop fires before any reset, INCR continues incrementing and `record_stop` keeps returning Alerts (because new_count >= threshold). This is documented behaviour — Plan 07's runner short-circuits before `record_stop` is ever called from the gate path. Phase 7 calls `record_stop` from the trade-close lifecycle, which only fires once per close. No deduplication needed in Phase 6.
- Use `ex=self._cooldown_seconds` (NOT `expire=` — that's the older synchronous redis API).
- `reset_if_expired` should be idempotent — calling it when no cooldown is set or when cooldown is still active returns False without errors.
- The `record_win` does NOT reset CB_TRIPPED_AT or CB_COOLDOWN_UNTIL — only the counter. AGENTS.md §12.3 says "counter resets on first winning trade", not "breaker resets". The breaker resets on cooldown expiry. This subtlety is intentional: a single win during cooldown clears the counter so the NEXT stop sequence starts fresh, but does NOT clear the cooldown lockout. This matches a real broker risk system.
