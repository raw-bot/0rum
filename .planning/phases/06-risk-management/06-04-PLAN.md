```python
    same_direction_open_count: int,
) -> PositionSizing:
    ...
```

Order of operations (06-CONTEXT D-07):
1. Compute `vol_factor`:
   - `if atr_pctile >= atr_high_vol_pctile / 100.0`: vol_factor = 0.7
   - `elif atr_pctile <= atr_low_vol_pctile / 100.0`: vol_factor = 1.3
   - `else`: vol_factor = 1.0
2. `risk_pct = risk_per_trade * vol_factor`
3. `risk_pct = min(risk_pct, hard_cap)` — apply cap AFTER vol bump
4. `concentration_reduced = same_direction_open_count >= 4`
5. `if concentration_reduced: risk_pct *= 0.5` — halve AFTER cap

Then:
6. `risk_amount = equity * Decimal(str(risk_pct))` — Pitfall 5 guard
7. `sl_distance = abs(entry_price - sl_price)` — Decimal subtraction
8. `if sl_distance == 0: size_lots = Decimal("0")` else `size_lots = (risk_amount / (sl_distance * Decimal("100"))).quantize(Decimal("0.01"))`
9. Return `PositionSizing(risk_pct=risk_pct, risk_amount_usd=risk_amount, size_lots=size_lots, vol_factor=vol_factor, concentration_reduced=concentration_reduced)`
